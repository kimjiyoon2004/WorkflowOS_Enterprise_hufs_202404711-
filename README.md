# Enterprise Workflow OS

> 사내 업무 흐름 통합 관리 및 데이터 기반 업무 분석 대시보드

## 1. 프로젝트 개요

본 프로젝트는 개인 업무 관리, 프로젝트 관제, 조직 자원 현황, 협업 커뮤니케이션을 하나의 화면에서 확인할 수 있도록 설계한 업무 통합 대시보드입니다.

흩어져 있는 업무 정보를 시간축과 우선순위 기준으로 정리하고, SLA 위험도, 프로젝트 진행률, 업무 완료 추이, 조직 업무량을 시각화하여 업무 의사결정을 지원하는 것을 목표로 합니다.

- 개발 기간: 2026년 5월
- 사용 기술: HTML5, CSS3, JavaScript
- 데이터 구조: JavaScript 기반 샘플 데이터 및 localStorage 저장
- 데이터 저장 방식: 브라우저 localStorage 기반 저장

---

## 2. 주요 기능

### 2.1 사원 업무 워크스페이스

개인 사용자가 오늘 해야 할 일, 예정 업무, 지연 업무, 완료 업무를 한 화면에서 관리할 수 있도록 구성했습니다.

- 출근 체크인 및 근무 유형 선택
- 개인 To-do 업무 등록, 수정, 삭제
- 완료 처리 및 진행률 조정
- SLA 기준 위험/주의/정상 업무 분류
- 퇴근 전 자동정리 리포트 생성
- 개인 업무 완료율 및 업무 처리 패턴 분석

### 2.2 운영 관제실

관리자 또는 운영 담당자가 전체 프로젝트와 조직 자원을 확인할 수 있는 화면입니다.

- 전체 프로젝트 수, 총 예산, 평균 진행률, 위험 프로젝트 요약
- 프로젝트별 예산, 진행률, D-day, 위험도 비교
- 프로젝트 상세 정보 확인
- 팀원 업무량 및 완료율 확인
- 단계별 병목 분석
- 회의실 사용 현황 및 다음 예약 확인
- 연간 업무 유형 비중 시각화

### 2.3 조직 구성원 관리

조직 내 구성원의 근무 상태와 업무량을 필터링하여 확인할 수 있습니다.

- 이름/이메일/프로젝트 검색
- 부서별 필터
- 역할별 필터
- 근무형태별 필터
- 프로젝트별 필터
- 완료율 및 업무량 비교

### 2.4 통합 일정 및 협업 관리

개인 일정과 조직 공유 일정을 구분하여 관리할 수 있도록 구성했습니다.

- 개인 일정 등록
- 개인 메모 등록
- 조직 공유 일정 확인
- 회의 및 마감 일정 표시
- 일정 수정 및 삭제
- 조직 공지 관리
- 공용 메일 관리
- 프로젝트 댓글 로그 관리

### 2.5 업무 지원 어시스턴트

개인 업무 화면에서 업무 우선순위, 병목, 과부하, 일정 리스크를 확인할 수 있는 보조 기능입니다.

- 오늘 업무 우선순위 안내
- 프로젝트 병목 요약
- 팀원 과부하 확인
- 일정 리스크 안내

## 3. 데이터 분석 및 시각화 요소

본 대시보드는 단순 업무 목록이 아니라, 업무 데이터를 분석 가능한 형태로 변환하는 데 중점을 두었습니다.

### 3.1 개인 업무 분석

완료 업무 기록을 기반으로 다음 항목을 시각화했습니다.

- 누적 완료율
- 주차별 완료 추이
- 우선순위별 업무 비중
- SLA 준수율
- 시간대별 완료 분포
- 요일별 위험도

### 3.2 프로젝트 분석

프로젝트별로 다음 지표를 비교할 수 있도록 구성했습니다.

- 예산
- 진행률
- 마감일까지 남은 기간
- 위험도
- 현재 병목 단계
- 팀원 업무량
- 프로젝트 건강도

### 3.3 조직 운영 분석

조직 전체의 업무 흐름을 파악하기 위해 다음 정보를 시각화했습니다.

- 구성원별 업무량
- 근무형태 분포
- 프로젝트별 인력 배치
- 회의실 자원 사용 현황
- 업무 유형별 비중

---

## 4. 실행 방법

1. `index.html` 파일을 Chrome 브라우저에서 실행합니다.
2. 로그인 화면에서 사원 또는 운영 관제실을 선택합니다.
3. 비밀번호 입력창에 `1234`를 입력합니다.
4. 각 메뉴에서 개인 업무, 프로젝트, 일정, 조직 현황을 확인합니다.
5. 업무를 추가하거나 수정하면 브라우저 localStorage에 저장됩니다.

## 5. 프로젝트 의의

이 프로젝트는 업무 관리 기능을 단순히 나열하는 것이 아니라, 실제 기업 내부에서 사용할 수 있는 업무 흐름 관리 시스템처럼 설계한 것이 특징입니다.

특히 개인 업무 관리, 프로젝트 관제, 조직 자원 관리, 협업 로그를 하나의 대시보드 안에 통합하여 다음과 같은 효과를 기대할 수 있습니다.

- 업무 우선순위 판단 지원
- 마감 지연 위험 조기 발견
- 프로젝트 병목 단계 확인
- 팀원 업무량 불균형 파악
- 퇴근 전 업무 정리 자동화
- 조직 단위 업무 흐름 시각화
